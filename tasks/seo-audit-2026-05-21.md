# SEO Audit — rankpointmedia.com

**Audited:** 2026-05-21
**Target:** https://rankpointmedia.com (production)
**Methodology:** six-pillar audit, weighted scorecard
**Auditor:** Claude (Opus 4.7), evidence-first, no fabricated metrics

---

## 1. Executive Summary

**Overall grade: C+, 75/100.**

The site has a sophisticated technical foundation — clean SSR, comprehensive schema markup, a sensible sitemap, intentional `noindex` on placeholder pages, and an editorial content voice that competitors do not match. Under the hood, the SEO work is meticulous. The problem is not the build.

The problem is what hasn't happened yet *around* the build. Google has indexed zero pages from rankpointmedia.com. The Google Business Profile does not exist. The LinkedIn page does not exist. No directory citations exist. And the dynamic OG image — referenced by every page's `<meta og:image>` — is returning HTTP 500, so every social share preview is broken on a site that just told us no one is sharing it anyway.

This is a launch-readiness gap, not a quality gap. Fixing the four critical items below would lift the grade to a B+ within a quarter without changing a single line of the build philosophy.

### Three biggest wins (preserve)

1. **Schema depth and accuracy.** 15 JSON-LD types across the site, zero parse errors. Service detail pages carry Service + FAQPage + BreadcrumbList. Case studies carry Article + BreadcrumbList. The root `@graph` carries WebSite + LocalBusiness + MarketingAgency with full geo, areaServed, and hours. This level of structured-data discipline is uncommon and will pay off the moment Google starts indexing.
2. **SSR with substantive content in raw HTML.** Every page tested returns 500+ words of indexable body content in the initial response — no client-side hydration dependency. Confirmed by `curl -s` vs WebFetch comparison across 31 pages.
3. **Intentional indexation hygiene.** `/areas/austin|dallas|houston` correctly return `meta robots="noindex, follow"` and are excluded from the sitemap. `/local/*` matrix gated behind `MATRIX_PAGES_LIVE` env var. The discipline of `noindex`-until-quality is the right instinct for a launch.

### Three biggest risks (fix first)

1. **Site is not in Google's index** (`site:rankpointmedia.com` returns zero own-domain results). Until this changes, every other SEO investment compounds at zero.
2. **`/opengraph-image` returns 500** site-wide. Every social share, every rich result preview, every "open in messenger" link shows a broken or default image. Verified with browser and `facebookexternalhit/1.1` user agents.
3. **No off-page presence at all** — no GBP, no LinkedIn, no Yelp, no BBB, no Clutch, no Bing Places, no Apple Business Connect. For a local services business, this is the single highest-leverage gap.

## 3. Pillar Deep-dives

The site is technically ready to be crawled and indexed. The blocker is not in this pillar (see Pillar 6). One process issue — stale `lastmod` values across all static URLs — costs nothing to fix and is the only meaningful Important finding.

### Pillar 5 — Technical performance — **C**

Grade is dragged into C territory by a single Critical issue (OG image 500) plus four real but fixable Important issues. Live Core Web Vitals data was not collected — PSI API hit a rate-limit and the user declined retries — so this grade reflects HTML-level signals plus header inspection only. Flagged in appendix.

### Glossary

- **Core Web Vitals (CWV)**: Google's three real-user performance metrics — Largest Contentful Paint (LCP), Interaction to Next Paint (INP), Cumulative Layout Shift (CLS).
- **CrUX**: Chrome User Experience Report — Google's public field-data dataset for CWV, populated from real Chrome users. New domains take ~28 days to appear.
- **GBP**: Google Business Profile (formerly Google My Business).
- **HSTS**: HTTP Strict Transport Security — header that tells browsers to only connect over HTTPS for a given duration.
- **JSON-LD**: JavaScript Object Notation for Linked Data — the schema.org markup format Google prefers.
- **lastmod**: The `<lastmod>` element in a sitemap.xml URL entry; signals when the page last changed.
- **LCP image**: The image element that Lighthouse identifies as the largest above-the-fold visual element on a page; the most important asset to optimize for LCP.
- **Map Pack / Local Pack**: The three Google Maps results that appear above organic results on local intent queries.
- **NAP**: Name, Address, Phone — the canonical business identity tuple. Consistency across the web is a local SEO ranking signal.
- **Preload**: `<link rel="preload">` — tells the browser to fetch a resource early, before the parser would discover it.
- **Programmatic SEO**: Generating many pages from a template (here, the `/local/[service]/[vertical]/[neighborhood]` matrix). Effective when each page has substantial differentiated content; risky when pages share boilerplate.
- **SSR**: Server-Side Rendering — the server returns HTML with content baked in, not an empty shell that JS fills.
